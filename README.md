
Grade Calculator

Name: Clark Kent P. Pastillero

Section: IT3R4

Description
This is a simple grade calculator made using HTML and JavaScript.
It calculates the average of three grades entered by the user.

Features
- Accepts three grades
- Validates grades from 0 to 100
- Calculates the average
- Displays the result

How to Run
1. Download or clone this repository.
2. Open the index.html file in a web browser.
3. Enter three grades.
4. Click the Calculate button.
5. View your average.
